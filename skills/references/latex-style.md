# LaTeX style (Neugier papers)

Template: `harness/paper/templates/main.tex` (amsart). Build: `python -m harness paper build --campaign <slug>`.
Lint: `python -m harness paper check --campaign <slug> --strict`. Appendix: `python -m harness paper repro --campaign <slug>`.

## 1. What may be stated

| Ledger status | Environment | Wording |
|---|---|---|
| `referee-passed`, `formalized` | `theorem`/`lemma`/`proposition`/`corollary` with `\claim{ID}` | "We prove …" |
| `proof-drafted` (review incomplete) | `conjecture` + a `remark` describing the partial argument | "We give a proof sketch …; a complete verification is pending." |
| `numerically-supported` | `conjecture` + evidence table | "Numerical evidence for n ≤ N …" |
| `known-in-literature` | theorem-like env **with `\cite`** and no `\claim` | "The following is due to …" |
| `refuted` | `proposition` (the refutation is the result) with `\claim{ID}` once referee-passed | "Conjecture X fails; a counterexample is …" |

`check.py` enforces this. Never work around it with plain text ("Theorem. …" outside an environment).

## 2. Structure

1. **Abstract** — one paragraph, states the exact outcome class honestly (new result / improvement of a constant / partial /
   negative / computational evidence). No superlatives.
2. **Introduction** — problem, conventions (mirroring `statement.md`), history with a **state-of-the-art table** (each row
   excerpt-backed), main results with ledger IDs, and a paragraph "What is new" pointing to the `\keystep`.
3. **Preliminaries** — definitions verbatim from `statement.md`; cited results stated with all hypotheses.
4. **Main argument** — lemma DAG order; every theorem-like env is immediately followed by its proof or a `\cite`.
   Exactly the genuinely new step is wrapped in `\keystep{...}` (at least one is required when a new theorem is claimed).
5. **Computations** — every number via `\numref{key}` or an explicit value that exists in `experiments/results.json`;
   tables generated by scripts, not typed.
6. **Limitations and open questions** — what was not proven; failed routes worth recording (from `ideas.md`), briefly.
7. **Computational details and reproducibility** — `appendix-repro.tex` (auto-generated; do not hand-edit).
8. **Tools disclosure** — which parts were machine-generated and how they were verified (ICM/IMU expectation).
9. **Bibliography** — `refs.bib` only; every entry resolved (`python -m harness lit checkbib`).

## 3. Macros

- `\claim{T-001}` — first token inside a theorem-like environment; binds it to the ledger.
- `\keystep{...}` — visible box marking the new argument.
- `\numref{key}` — typeset a computed quantity by its results.json key (copyeditor replaces or verifies).
- `\assumes{...}` — conditional results state their assumptions up front.

## 4. Writing rules

- No hedge words (`clearly`, `well known`, `obviously`, `standard`, `trivially`, `one can show`): give the argument or a citation.
- No numbers in prose that are not in `results.json` (years and small integers excepted).
- Cited statements must match the source excerpt; do not "improve" a cited theorem.
- Notation defined once, in Preliminaries; no notation changes mid-paper.
- Proof steps keep the numbering of the proof artifact so referees can cross-reference (`Step 4` ↔ `proofs/T-001.md`).
- Attribute AI-generated constructions/computations explicitly; attribute ideas from the literature explicitly.
- English; American spelling; theorem-like environments numbered within section; `\label`s `thm:`, `lem:`, `eq:`, `tab:`, `fig:`.

## 5. Build hygiene

- `tectonic` is project-local (`bin/`), cache in `.cache/tectonic`; first build downloads packages.
- Keep `paper/` self-contained: `main.tex`, `refs.bib`, `appendix-repro.tex`, `figures/`.
- `check.json` must have `"ok": true` before the Write phase can exit; warnings should be zero for submission.
